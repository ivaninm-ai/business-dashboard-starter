你的仓库 › Settings › Pages

比喻：GitHub Pages 是 GitHub 免费借你的一块展示橱窗。这一步只是告诉 GitHub：“橱窗里的东西，由我的自动流程来摆。”

卡住了？看不到 Settings：你打开的多半是老师的模板，不是你自己的仓库——看左上角是不是你的用户名。

第 3 步

设定你的店名

你的仓库 › Settings › Secrets and variables › Actions

不用改任何文件：在仓库的设定里加一个变量。下一步发布网站时就会用上：你的网站左上角会显示你的店名。

⚙️打开我的变量设定前往 GitHub ↗

  1. 按上面的按钮（或在你的仓库里点 Settings → 左边 Secrets and variables → Actions → 上方的 Variables 分页）。
  2. 按 New repository variable，照下表填 Name 和 Value，再按 Add variable。
    Name（照抄）Value（你填）作用
    BUSINESS_NAME你的店名，例如 小明家具店网站左上角和浏览器分页显示你的店名。最多 40 个字。
  3. 加好之后，Variables 分页会列出这个变量。接着做第 4 步，发布你的网站。
比喻：变量就像店门口的招牌。换招牌不用拆店：代码一行都不动，只换设定。
⚠️ 要加在 Variables 分页，不是 Secrets。变量会写进网站，任何人都看得到：只放店名这类公开资料，不要放密码或钥匙。

以后想改：回到同一页，按变量旁边的铅笔改 Value，再发布一次（第 4 步）。改了变量一定要重新发布，网站才会更新。

检查

卡住了？看不到 Settings：你打开的多半是老师的模板，不是你自己的仓库。不小心加到 Secrets 分页：删掉它，改加在 Variables 分页。暂时不想设：可以跳过这一步，网站左上角会显示你打开的 Excel 的文件名；以后再回来加，重新发布就好。

第 4 步

发布你的网站

你的仓库 › Actions

🚀打开 Publish site前往 GitHub ↗

  1. 点顶部的 Actions → 左边选 Publish site。
  2. 右边按 Run workflow → Branch 保持 main → 按绿色的 Run workflow。
  3. 刷新一下页面，会出现一条黄色圆点的运行记录。等 1–3 分钟，变成绿色勾就完成了。它会先自动检查（打包 + 所有测试），全部通过才会发布。
  4. 打开你的网址：https://用户名.github.io/仓库名/（第一次可能要再等 1 分钟）。
检查

卡住了？
· Actions 页面叫你启用 workflows：按 I understand my workflows, go ahead and enable them，再回到这一步。
· 红色叉叉，失败在 Configure Pages 或 deploy：回第 2 步，确认 Source 是 GitHub Actions，然后再 Run workflow 一次。
· 红色叉叉，失败在 Run npm run check：多半是第 3 步的变量有问题。点开看红字，它会写明原因，例如 BUSINESS_NAME 太长了。回到 Variables 改好，再 Run workflow 一次。红字说的不是变量：把截图发到学员群。网站不会被改坏。
· 店名没变：确认第 3 步的 Name 全是大写、没有空格；变量要在按 Run workflow 之前加好。加晚了就再 Run workflow 一次，然后按 Ctrl + F5。
· 网址显示 404：等 1–2 分钟再重新载入；检查网址里的用户名和仓库名；仓库要是 Public。

第 5 步

打开你自己的 Excel

你的网站

网站本身没有任何数据：你打开一个 Excel，数字、待办和日历就按里面的记录算出来。文件只在你的浏览器里读取和计算，不会上传到 GitHub 或任何地方，也不会出现在别人打开的网站上。

  1. 打开你的网址。页面写着「打开你的 Excel」。
  2. 准备 Excel：老师给了练习用的 Excel，就直接用它，跳到下一步。还没有文件：在页面下方按 下载 BetterSpace_B2B.xlsx（虚构的练习数据）。已经有自己的 Excel：直接用它，格式不一样也可以（见第 4 点）。
  3. 回到网站，按 选择 Excel 文件，选你的文件。和练习工作簿同样格式的文件，数字、待办和日历马上算出来；报告日期是文件里最新的日期。
  4. 格式不一样（例如工作表名、列名是中文，或状态写法不同）：页面会出现 对应你的列。仪表盘已经先猜好了哪个工作表是订单、客户、收款、库存，哪一列是什么、你的状态写法是什么意思——检查一遍，不对的就从下拉选单改，然后按 用这个对应打开。只要做一次：下次读取同样格式的文件会自动套用；想改就按上方的 修改对应。以后在 Excel 里加了列、改了列名或多了工作表，这一页会再出现一次，但你之前的选择已经填好，只要检查改变的地方。
练习工作簿的工作表一定要有的列（对应时也要选到）
Customerscustomer_id, customer_name
Salessale_id, sale_date, total_amount
Paymentspayment_id, sale_id, payment_date, amount
Stockitem_id, on_hand_quantity

只有订单一定要有；没有客户、收款或库存工作表也可以，那几页会自动隐藏。其他列（状态、付款期限、负责人等）有就选上；没有的话，用到它们的数字会留空或为零。

⚠️ 「状态」指的是订单或服务有没有做完，不是有没有付钱（付款会从收款工作表计算）：「已付」「已开单」「未付」通常都选「已完成」，「作废」「取消」选「取消」。日期用 Excel 日期，或写成 2026-08-30、30/08/2026；金额用数字或写成 RM 12.50。
⚠️ 文件会记在这个浏览器里，但这不是备份。不要在共用电脑上打开机密的真实数据。
检查

卡住了？「对应你的列」最下面写着「还要回答……」：照它说的选好那一项。按了打开却列出问题：看第一个问题，会写明是哪个工作表、哪一行、哪一列——多半是选错了列（例如把单价当成金额），或 Excel 里有写错的日期、金额。文件是 .xls / .csv：要在 Excel 里另存为 .xlsx。

第 6 步

试用你的仪表盘

你的网站
  1. 看 概览，再打开 订单、客户、收款、库存；点表格里的一行，就能看到数字背后的那笔记录。右上角可以切换 中文 / English。
  2. 打开 待办（Tasks），按一条建议的 接受（Accept），再按 编辑（Edit） 改行动日期 → 保存。
  3. 打开 日历（Calendar）：这条待办出现在你选的日期上。按 + 新增备注 加一条你自己的备注。
  4. Excel 改过之后：在 Excel 里保存，回到网站按 重新读取 Excel。数字跟着变，同一笔记录的决定会保留。
  5. 想从头来：按 清除待办决定和备注（文件会保留）。不用这个文件了：按 忘记这个文件。
⚠️ 你的 Excel 和操作只保存在这台电脑的这个浏览器里。这不是备份：换电脑、换浏览器或清除浏览器数据，就要重新打开 Excel。别人打开你的网址，看不到你的 Excel 和操作；想给同事看，就请他在自己的电脑上打开同一个 Excel。

第 7 步

请 Gemini 分析你的数字

Google AI Studio → 你的网站 › AI 分析

用 Google 免费的 Gemini，按你网站上现在的数字写一份分析。你只要拿一把免费的钥匙（API key），贴到你的网站一次，以后按一个按钮就好。

🔑打开 Google AI Studio 的钥匙页前往 Google ↗

  1. 按上面的按钮，用 Google 账号登录 Google AI Studio。第一次会请你同意使用条款。
  2. 在钥匙页找到你的 API key，按旁边的复制。还没有钥匙：按 Create API key，再复制。
  3. 打开你的网站 → 左边 AI 分析 → 「用 Gemini 分析」卡片 → 把钥匙贴进方框 → 按 保存钥匙。看到「钥匙已存在这个浏览器（尾号 …）」就对了。
  4. 按 用 Gemini 分析。等 10–30 秒。
  5. 答案出现在按钮下面，标着「实时 AI」。下面的数字核对会告诉你：答案里的数字是不是都能在你的数据里找到。
比喻：仪表盘是帮你算账的会计，Gemini 是听完报告给意见的顾问。钥匙就像顾问的会员卡——每次请顾问，都要出示你自己的卡。
⚠️ 钥匙就像密码。只贴在你网站的「用 Gemini 分析」里：绝对不要放进 GitHub（仓库变量也不行——变量会写进公开的网站），不要贴到群里，也不要截图分享。钥匙只存在你这台电脑的这个浏览器；换电脑要再贴一次，不用了就按「删除钥匙」。
⚠️ 按「用 Gemini 分析」会把你的数字送到 Google。Google 的免费方案会用送出的内容改进产品，并请你不要送出个人或机密资料。客户和员工的名字默认会换成代号；真实的业务数据，先确认你可以分享。
检查

卡住了？
· 「Google 不接受这把钥匙」：回 AI Studio 重新复制整串钥匙，在网站按「删除钥匙」，再贴一次。
· 「免费额度暂时用完了」：等一分钟再按，或明天再用。
· 「连不上 Google」：检查网络。用双击打开的离线文件也要电脑联网才能分析。
· 数字核对列出了一些数字：那是 AI 自己编的或算错的，以仪表盘为准。

第 8 步

请 AI 帮你加功能

claude.ai/code → 你的仓库

想加新指标、图表或页面？交给 Claude Code：你用一句话说要什么，它在 Claude 的云端电脑上改代码、跑检查，再把修改交给你批准。你不用写代码，也不用安装任何软件。需要付费的 Claude 订阅（Pro、Max 或 Team），用量和你平常用 Claude 聊天算在一起。

🤖打开 Claude Code前往 Claude ↗

  1. 按上面的按钮，用你的 Claude 账号登录。
  2. 第一次用：照画面提示连接 GitHub。安装 Claude 的 GitHub App 时选 Only select repositories，只选你的仓库 https://github.com/用户名/仓库名。云端环境（environment）用默认的就好。
  3. 在输入框下面选你的仓库，分支选 main。输入框旁边的模式选 Plan：它会先写计划，等你批准才动手。
  4. 在输入框用一句话写你要什么，并请它先安装、先读规则、做完跑检查。例如：
    先运行 npm ci。请先读 AGENTS.md。 在概览加一个「本期服务类订单额」KPI，加上中文翻译和测试， 运行 npm run check，用中文告诉我结果，以及你没能验证的地方。
  5. Claude 会先写计划：看得懂就批准；看不懂就请它用中文解释。
  6. 等它做完（几分钟到半小时），在修改画面上方按 Create PR。它会在你的仓库开一个 Pull request。
  7. 回到你的仓库，点上方的 Pull requests → 打开它 → 等 Tests 变成绿色勾 → 按 Merge pull request → Confirm merge。
  8. 照第 4 步运行 Publish site，在你的网址上看看新功能（中文和英文都看一下）。
比喻：Pull request 是 AI 交来的「修改申请书」。你按 Merge 才算批准；不按，你的网站什么都不会变。

新增指标

例如「本期服务类订单额」。打开练习工作簿 BetterSpace_B2B.xlsx 时，8 月应为 RM 3,400（5 笔）——用这个数字检查 AI 做得对不对。

新增图表

例如「按产品的订单额」。用现成的横条图，颜色只用已有的颜色。

新增待办规则

例如「感谢回头客」。每条建议的编号要稳定，重新读取 Excel 后决定才对得上。

新增页面

例如「产品」页。复制一个现有页面，再加到菜单里。

Claude Code 会自动读仓库里的 CLAUDE.md，它指向 AGENTS.md：里面写着不能改坏的规则——数字必须从记录算出来、网站不内置数据、只连 Gemini、代码里不放钥匙、所有文字要有中文翻译、AI 的内容要诚实标明。完整技术说明在 docs/STUDENT_SOP.md。

⚠️ Tests 是红叉的 Pull request 不要 Merge。也不要让 AI 把任何 API 钥匙写进网页代码——网站是公开的，任何人都能看到。Claude Code 的对话保持 Private，不要设成 Public。
检查

卡住了？
· 画面说你的方案不能用 Claude Code：免费方案不包含 Claude Code，要 Pro、Max 或 Team。
· 找不到你的仓库：在 GitHub 按右上角头像 → Settings → Applications → Claude 旁边的 Configure，把仓库加进去。
· Pull request 的 Tests 是红叉：不要 Merge。回到同一个 Claude Code 对话，请它「修好测试，再更新 Pull request」。
· 用量到了上限：等额度恢复再继续。Claude Code 和你平常用 Claude 聊天共用同一个额度。
· Merge 之后发布出现红叉：网站仍是上一个正常版本。把 Actions 里失败那一步的截图贴给 Claude Code，请它修。

规则与限制

要记住为什么
你的 Excel 只在你的浏览器里它在你的电脑上读取，不会上传，也不会发布到你的网站上。按「忘记这个文件」就会从浏览器删除。
本地保存不是云端备份网页上的操作只存在那台电脑的那个浏览器里；没有登录、没有同步、没有共享。
AI 的回答要自己核对AI 会说错数字或编理由，以仪表盘为准；数字核对会帮你找出对不上的数字。送到免费 Gemini 的内容，可能被 Google 用来改进产品。
钥匙只放在一个地方Gemini 钥匙只贴在你网站的「用 Gemini 分析」里，存在你的浏览器。不要放进 GitHub、仓库变量、群聊或截图。
你的版本可以自由使用模板用 MIT 授权：你可以修改、自己用、商用，也可以请程序员帮你扩展，只要保留仓库里的 LICENSE 文件。软件按「原样」提供，不附带任何保证。
网站不含你的数据网站本身没有任何业务数据；你的 Excel 只在你的浏览器里读取。仓库是公开的：不要把你的 Excel 文件放进仓库。这是学习项目，不适合机密的真实业务数据。
每次修改都要重新发布改了变量、Commit 或 Push 之后，都要运行 Publish site，网站才会更新。检查没通过就不会发布。
报告日期是 Excel 里最新的日期数字都按文件里最新的日期（销售、收款、完成、库存盘点）计算，不是电脑今天的日期。
格式不同的 Excel 要先对应第一次打开时回答「对应你的列」。仪表盘能读懂的是订单、客户、收款和库存这几种记录；其他记录（例如上课出席、会员积分）会被忽略。
想让同事看同样的数字把同一个 Excel 发给他，请他在自己的电脑上打开你的网址、选这个文件。网站不会替你共享数据。
