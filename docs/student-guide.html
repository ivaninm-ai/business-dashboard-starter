🚀打开 Publish site前往 GitHub ↗

检查

卡住了？红色叉叉：回第 2 步确认选了 GitHub Actions，再 Run workflow 一次。网址显示 404：等 1–2 分钟再刷新。

可选：显示你的店名。打开 变量设定 → New repository variable：Name 填 BUSINESS_NAME，Value 填店名 → Add variable，再 Run workflow 一次。要加在 Variables，不是 Secrets。

第 6 步

请 Gemini 分析

🔑拿免费的 Gemini 钥匙前往 Google ↗

  1. 用 Google 账号登录，复制你的 API key。没有就按 Create API key。
  2. 在你的网站打开 AI 分析，贴上钥匙，按 保存钥匙。

第 7 步

让 AI 帮你改网站

先看懂：它们怎么连在一起

你用一句话说要什么
↓

↓ 交一份修改申请
GitHub · 你的仓库
Pull request修改申请，自动跑 Tests

main网站的原稿
↓ Publish site
你的网站GitHub Pages
你的 Excel 只在浏览器里打开这个网站，不会进 GitHub，也不会给 Claude。
  • GitHub 仓库是你网站的「原稿」，代码都在这里。
  • Claude Code 是你请来的工程师。你用 GitHub App 给它一把只开这个仓库的钥匙；它复制一份来改，不会直接动你的原稿。
  • 改好后它交一份修改申请（Pull request），GitHub 自动跑 Tests 检查。你按 Merge 才算批准。
  • 批准后再 Publish site，网站才会更新。

① 连接 GitHub（只做一次）

🤖打开 Claude Code前往 Claude ↗

  1. 用 Claude 账号登录，照提示连接 GitHub。
  2. 安装 Claude 的 GitHub App 时选 Only select repositories，只勾你的仓库。

想看或收回这把钥匙：GitHub 右上角头像 → Settings → Applications → Claude → Configure。

② 提出修改

  1. 选你的仓库和 main，模式选 Plan。
  2. 选一个开始，复制后贴进去：
    加一个你关心的数字
    先运行 npm ci。 在概览加一个「本期服务类订单额」KPI，加上中文翻译和测试， 运行 npm run check，用中文告诉我结果。
    用练习 Excel 检查：8 月应为 RM 3,400（5 笔）。
    改成你行业的叫法
    先运行 npm ci。 把菜单和标题里的「订单」改叫「工单」（英文 Orders 改成 Jobs）， 运行 npm run check，用中文告诉我结果。
    加一个图表
    先运行 npm ci。 在概览加一个「按产品的订单额」横条图，加上中文翻译， 运行 npm run check，用中文告诉我结果。
  3. Claude 会先写计划：看得懂就批准；看不懂就请它用中文解释。

③ 检查和上线

  1. 它做完后，按 Create PR。
  2. 回到 GitHub 你的仓库 → Pull requests → 等 Tests 出现绿色勾 → Merge pull request → Confirm merge。
  3. 照第 3 步再 Run workflow 一次，打开你的网站看看。
⚠️ Tests 是红叉，就不要 Merge。Claude Code 的对话保持 Private。
检查

要记住

  • 仓库和网站是公开的：只放练习数据。
  • 钥匙只贴在你的网站里。
  • Excel 只在你的浏览器里，不会上传；这不是备份。
  • 改了任何东西，都要再 Run workflow 一次，网站才会更新。
