# Publishing the template (instructor checklist)

Nothing here has been done yet. The repository exists only on this computer, with no
remote. Each step that creates or changes something online needs the course owner's
go-ahead.

## Before publishing

1. **Choose a license.** The original Business Dashboard template has no license file, so none was
   copied. Without one, students may view but not legally reuse the code. A permissive licence
   (for example MIT) suits a class starter; state separately that the BetterSpace records are
   synthetic training data.
2. **Read the four prepared briefs** in `src/briefs/examples.js` (or on the *Example analysis* page
   in both languages). Their numbers are checked automatically; their wording and emphasis are
   the instructor's call.
3. Run `npm run check` and open `dist/business-dashboard-demo.html` once more.

## Publish (needs approval)

1. Create an empty repository under the course account, e.g. `business-dashboard-starter`
   (public, no README/licence generated by GitHub).
2. `git remote add origin <url>` and `git push -u origin main`. The **Tests** workflow runs on
   that push (no secrets). The **Publish site** workflow does nothing until someone runs it.
3. Settings → General → tick **Template repository**, so students see **Use this template**.
4. Create a release (e.g. `v0.1.0`) and attach `dist/business-dashboard-demo.html`, so students
   can download the offline demo without installing Node. `dist/` is not committed.
5. Optional: publish the class copy to GitHub Pages — Settings → Pages → Source: GitHub Actions,
   then Actions → **Publish site** → Run workflow. The page (and every record in it) is public.
6. Share the template link and `docs/student-guide.html` (or the release) with students.

## Keep separate

- This starter is independent of `business-dashboard/` (the Google Sheets template). Do not push it
  to `ivaninm-ai/analysis-dashboard-template`, and do not redirect that project's installation
  guides or Artifact here.
- Students' copies are theirs: they publish under their own accounts; nothing is hosted or paid for
  by the course.
